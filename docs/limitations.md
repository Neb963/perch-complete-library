# Limits and unsupported claims

- No built-in generator UI, generic workflow automation, mandatory state server, login system, CDN plugin loader, or centrally hosted JavaScript runtime.
- The old reference-generator action reducers and Stage 3 diagnostic page are excluded from stable package exports.
- No live proof of optional upload or CORS-sensitive classification; these remain internal source, not supported public subpaths.
- No saved/public generation or upload claim is conveyed by preview evidence.
- Portable KV export/import is not an atomic global transaction, and full 240 MiB archives have not received empirical peak-memory validation.
- Native uncertainties, late callbacks, tab concurrency and network-side effects cannot be reduced to deterministic offline fakes. Preserve typed uncertainty.
- The package name is a source-package identity; **npm registry availability and publication are not established**. Obtain owner approval for a registry release separately.
