# Provenance and boundaries

This library is derived from a separately frozen Stage 3 implementation. The archived ZIP SHA-256 and build identity are recorded in `stage3-freeze.json`. Archive bytes, historical screenshots, platform skill snapshots, and live logs are **not** embedded in the public source repository to avoid republishing third-party documents and unreviewed diagnostic data. Contact the project maintainer for provenance verification. Relocated source retains the Stage 3 implementation license declaration (MIT); the new repository MIT notice applies to owned code. Verify third-party licensing before importing code from external archives.

Native observations are historical for their exact build and do not automatically qualify changed distribution artifacts.
